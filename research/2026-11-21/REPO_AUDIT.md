Baseline: `a9dcbde`, 2026-07-09, `Abteeeen/higgsfield-prompting-skill`. All ten original Markdown files were read. The related `prompt-engine` repository was discovered and its tree inspected, but it was not fully audited.

| Historical claim or routing | Correction |
|---|---|
| README calls this an official wiki and routes every task to Seedance 2.0 | This is an independent lab. Route by platform, selected model and mode. |
| JSON described as direct private engine control | Treat JSON as organization unless a current API schema explicitly documents the field. |
| Fixed `<<<image_N>>>`, `@source`, `@motion` or capitalization assumed universal | Use the real host's reference selector and identifiers. Plain strings do not prove asset attachment. |
| Exact timestamps, camera commands and source locks treated as guarantees | They express intent. Inspect the rendered result; finish precise timing in an editor. |
| Soul ID treated as universally applied identity training | Check whether the selected model actually supports the asset and mechanism. Elements and model-specific identity tools are not interchangeable. |
| Seedance 2.0 input/duration limits applied to later models | Keep version-specific limits separate. The live 2.5 catalog and current web controls differ from older notes. |
| Old Dreamina availability, resolution, pricing and Mini-only assumptions | Recheck current account and regional availability. November official announcements include Seedance 2.5 and 4K; old help pages can lag. |
| Guaranteed 4K realism or recovered detail | Resolution, upscaling and regeneration describe different processes, none guarantees correctness. |
| Percentages such as 91%, 73%, 90% success, 500-run claims and model rankings without auditable methods | Retain only as historical unsupported claims; do not use them as evidence or repeat them as benchmarks. |
| Conflicting universal word limits and mandatory camera motion | Match detail to the scene. Static framing is valid; measure failures rather than imposing a magic length. |
| Prize and view outcomes treated as predictable | Record official tiers and eligibility. Reach and payment remain uncertain. |

The old README and SKILL are preserved unchanged under `archive/2026-07/`. The other eight original documents retain their content with a historical notice. Current entry points now direct readers to sourced workflow guidance and explicit research gaps.
