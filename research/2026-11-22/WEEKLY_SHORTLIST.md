## Recommendation and production strategy

Choose **#1 for the strongest observed audience signal**, with the tradeoff of difficult character and emotional continuity. Choose **#2 for a more controllable first production concept**: staged transformation in one location gives us fewer identities and interactions to manage. These are production judgments, not forecasts of reach. #5 is a lighter alternative if the user prefers visual comedy. No niche commitment is needed.

1. The user selects a reference direction. Write an original premise and ending before prompts. Preserve the useful hook/pacing mechanism, rather than merely swapping a character in the same film.
2. Draft a 35–45 second storyboard with roughly six to eight shots: immediate visual question, clear setup, two or three developments, then payoff. This length is a proposal for our eventual piece, not a claim about the source or program eligibility.
3. Build a continuity sheet: character appearance, object dimensions, wardrobe, lighting, geography and the state of each asset after each shot. Transformation scenes need explicit before/after stage references; emotional stories need a stable relationship and readable motivation.
4. Write each shot as **reference roles → subject and setting → observable action → camera → continuity constraints → audio**, using only controls actually available in the selected platform/model. Higgsfield and Dreamina are interfaces containing multiple workflows; they do not each have one universal prompt language. Do not paste incompatible camera instructions or assume a named model supports every control.
5. After explicit generation authorization, test the chosen story's hardest interaction in Higgsfield. Inspect the complete result and change one variable per retry. A successful test establishes feasibility, not likely views. Confirm Unlimited availability before any submission; no automatic credit fallback.
6. After separate production/release authorization, evaluate the opening, completion/retention, shares per view and comments at comparable post ages. Use our own baseline rather than invented universal thresholds. Keep/revise the format from observed results. Ten million views are a target, not an expected consequence of a remake.
